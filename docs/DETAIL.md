# 对话内搜索（dsh-conversation-search）

同一段对话动辄几十上百轮，想回头找「我前面某一轮到底说过什么」时，
浏览器自带的查找只能看见当前已经渲染出来的那一段。本插件在会话输入框
左侧加了一个搜索按钮，可以按关键词直接检索**当前对话**的全部消息。

## 用法

1. 在任意会话输入框左下角点放大镜图标，或按 `Ctrl+Shift+F`（macOS 上
   `Cmd+Shift+F`）打开搜索面板。
2. 输入一个或多个关键词，多个关键词用空格分隔，结果为**同时包含全部关键词**
   的消息。
3. 结果按 `我`（你发送的提示词）与 `模型`（模型回复的文本）分组显示，可以
   用顶部的「全部 / 我的 / 模型」筛选。
4. 每条结果显示轮次、时间、命中次数和带高亮的摘要；点击展开全文，
   展开的内容按 Markdown 渲染（代码块、表格、列表，数学公式走 KaTeX，
   与聊天区一致），点「复制」可复制该条消息的完整原文，点「跳转」则回到
   聊天区对应的那一轮并闪一下高亮。
5. 对话很长、更早的历史还没载入时，底部会出现「继续搜索更早的对话」，
   点击后插件会按需拉取更早的消息页并继续搜索。
6. 键盘操作：`↑` / `↓` 选择，`Enter` 展开，`Alt+Enter`（macOS 上
   `Cmd+Enter`）跳转，`Esc` 关闭。

## 设计说明

- **纯客户端**：搜索直接跑在同一会话的客户端事件窗口上
  （`ctx.sessions.binding(sessionId).eventSource`），不需要 Host 服务、
  不上传任何内容、不新增网络请求。
- **按需载入历史**：更早的消息通过 `session.loadOlder()` 逐页拉取，
  与聊天视图“向上滚动加载更早消息”走同一条路径。
- **只搜文本**：命中范围是你发送的提示词、模型回复中的正文文本
  （`text` 块），不包括推理过程、工具参数和工具结果。
- **Markdown 渲染**：展开结果复用应用自带的 `MarkdownText`
  （`@deepseek-ai/dsh-client-ui-primitives`），公式由 KaTeX 渲染；
  该模块不可用时自动退回纯文本，功能不缺失。
- **跳转**：聊天行带有 `data-chat-turn` 属性，插件据此定位并
  `scrollIntoView`；目标轮尚未载入时先调用 `session.loadThrough(seq)`
  把历史拉到位再滚动。这是依赖聊天内部属性的尽力而为实现：DSH 调整
  该属性后会退化为“该轮次尚未载入，请先向上滚动加载”的提示，不影响搜索。

## 兼容性

- 平台：DSH Web（`platform: "web"`）。
- 需要 DSH `0.2.2-rc.1` 及以上、`0.2.3` 以下。
